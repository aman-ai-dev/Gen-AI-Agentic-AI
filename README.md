# Gen-AI Agentic AI System

## Overview
This project demonstrates an **Agentic AI system** where an LLM plans tasks, selects tools, executes actions, and reflects on outcomes.
The focus is on **agent architecture**, not just model prompting.

## Key Concepts Covered
- Planner → Act → Observe → Reflect loop
- Tool calling & tool abstraction
- Memory handling (context passing)
- Guard / validation logic
- Error handling & replanning

## Tech Stack
- Python
- Jupyter Notebook
- LLMs (API-based)
- Custom agent logic

## Project Structure
- notebooks/ → experiments & iterations
- agents/ → planner, executor, critic logic
- tools/ → external tool interfaces
- utils/ → helpers & abstractions

## What This Project Shows
- Understanding of agent workflows
- Separation of concerns in AI systems
- Real-world agent design patterns

## Future Improvements
